# site-editor-client

Public client assets (editor.js / editor.css / bootstrap.js) for the METIS site editor, served via jsDelivr.
Server code is kept private in the separate `site-editor` repo.

**CDN (pin a version tag):**
```
https://cdn.jsdelivr.net/gh/seindjat/site-editor-client@v1/editor.js
https://cdn.jsdelivr.net/gh/seindjat/site-editor-client@v1/editor.css
```
Each site sets `editorBase` in its own `editor.config.js` to the tagged CDN base.
